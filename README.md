# Wallhaven 壁纸（安卓第三方浏览 App）

一个给自己用的 wallhaven.cc 浏览客户端：看榜单、搜索筛选、看大图、下载壁纸、本地收藏。界面按 iOS 26/27 的“液态玻璃”风格重做，**默认浅色**，跟随系统切换深色。代码全在 `D:\projects\wallhavenTools` 里。

---

## 一、装到手机上（最短路径）

要装的文件就一个：

```
D:\projects\wallhavenTools\Wallhaven壁纸-v1.7.9.apk
```

**步骤：**

1. 用微信/QQ/数据线/网盘把上面这个 `.apk` 文件传到手机上（放哪都行，比如「下载」文件夹）。
2. 在手机上点开这个文件。
3. 手机会提示「为了安全，禁止安装未知来源应用」——点「设置」，把允许来源的开关打开（不同品牌文字略有差异：允许安装 / 未知来源 / 外部来源应用）。
4. 回到安装界面，点「安装」。
5. 装好后桌面上会有「Wallhaven 壁纸」图标，点开即可。

> 从 1.0.0 升级的话直接覆盖安装即可，收藏和历史都还在。

**装之前先确认一件事**：你的手机网络能打开 wallhaven.cc。这个站国内一般需要开 VPN / 代理，App 本身不带翻墙功能。如果站点打不开，App 里会显示「解析不到 wallhaven.cc / 连接超时」，这时候先解决网络，不是 App 的问题。

## 三、能做什么

| 页面 | 功能 |
|---|---|
| 榜单 | 自动识别本机屏幕比例，优先展示贴合的壁纸（手机上是竖屏）；热门（近一个月排行）、最新上传、随机、浏览最多、收藏最多，滑到底自动加载下一页 |
| 搜索 | 关键词/标签搜索（**清空关键词自动回到默认列表**）；**最近搜索历史**（点一下重新搜，可清空）；分类筛选；**高级筛选**（关键词必含/必排、方向、多选比例、最低分辨率+自定义宽高、多选主色、文件大小、上传时间、排序组合、**收藏常用标签**、**分级三选 SFW/Sketchy/NSFW**） |
| 详情 | 大图预览（同图模糊作背景），双指缩放、双击放大；**标签可点击，按标签搜索**（最多 12 个）；**「更多类似」按标签+主色找相似壁纸**；**轻点图片会把底部信息面板和顶部按钮一起收起**，再点一下恢复；**点面板空白处不会误收起**；按钮显示的是「点一下会切到哪」（预览中是「原图」，原图中是「预览」）；**下载按钮带进度条，下完变「下载完成」，再点直接去已下载列表**；看分辨率、大小、格式、浏览量、收藏数、上传者；下载、收藏、分享链接、用浏览器打开原站 |
| 收藏 | 本地收藏存在本机；**登录 wallhaven 账号后可读取云端收藏，并把本地收藏同步上去**；自动统计收藏里的常用标签（前 10，点一下按标签搜索），缺标签的会自动补全；右上角眼睛按钮**默认隐藏 Sketchy / NSFW 卡片**，一键切换；取消收藏、清空收藏都有多次确认 |
| 历史 | 自动记录看过的壁纸（最多 200 条），可清空 |
| 设置 | **已下载壁纸**（查看/删除相册里的下载文件）、**检查更新**（从 GitHub 拉最新版并直接安装）、下载位置说明、清理图片缓存、清空收藏/历史、打开官网、网络与版权说明；**卡片预览方式**、**诊断：运行日志、复制设备信息**、**关于作者（GitHub）与开源组件** |

**本机比例适配**：App 启动时读取屏幕像素（例如 1080×2400 → 9:20），首页默认只拉取接近手机屏幕方向的壁纸，并在每一页内按“与本机比例的差值”排序，最贴合的排最前。榜单顶部有个「适配本机 9:20」的开关，点一下可切回「全部比例」，选择会记住。设置页的「显示」区块能看到识别出的比例。

**高级筛选都在哪**：搜索页点「高级筛选」，里面比官网多这些东西——关键词必含/必排（自动转成 `+标签 -标签` 语法）、**画面方向默认就是「本机 9:20」**、竖屏/横屏/方形、画面比例多选（16:9、21:9、9:20…可叠加）、最低分辨率预设 + 自定义宽高、主色多选（可叠加多个颜色）、只看 ≥N MB 的图、只看最近 N 天上传的图、**收藏里最常用的 10 个标签（点选即 `+标签`）**。生效后筛选按钮会显示数量，下面还有一行文字汇总当前条件。

**搜索历史**：搜过的关键词会记在搜索页顶部「最近」，点一下直接重新搜，点右侧 × 清空；只存本机，最多 12 条。

**标签怎么用**：详情页往下是标签区，点任意一个 `#标签` 就跳到搜索页按该标签搜索；收藏页会把收藏图里出现最多的 10 个标签列出来，点一下同样按标签搜索。

**运行日志（排查问题用）**：设置页有「诊断」区，点「运行日志」能看到最近发生了什么——每次网络请求（地址、状态码、耗时）、下载、分页错误、崩溃堆栈都会记下来。日志只写在本机 `files/logs/app.log`，最多保留 800 条 / 256KB，不会上传。页面顶部有一张诊断卡（版本、系统、机型、屏幕、日志条数），右上角三个按钮分别是**复制全部**、**分享**（微信/邮件发给我都行）、**清空**；上面还有「全部 / 错误 / 警告 / 信息」筛选，出问题先点「错误」最快。

**账号与云端收藏**：设置 → 账号 → 登录 wallhaven 账号。登录页是在 App 内打开的**官网真实登录页**，密码只输入给 wallhaven，App 不接触也不保存密码，只保存登录后的会话 Cookie（退出登录即清除）。登录后收藏页会多出「账号」标签，能看到账号里的收藏；右上角两个按钮分别是「刷新云端收藏」和「把本地收藏同步上去」（只新增、不删除，逐张间隔约 0.9 秒）。注意：这是模拟网站操作，不是官方 API，网站改版可能失效，失败原因都会写进「运行日志」。

**卡片预览**：默认按壁纸**真实比例**显示完整图（竖图不会再被裁掉一截）。注意 wallhaven 提供的缩略图本身是 16:9 裁切的，所以「完整预览」用的是它保留原比例的 `thumbs.original`（长边 300px），大卡片上会略糊；设置 → 显示 → 「卡片显示完整壁纸」可以关掉，换成 16:9 缩略图填满卡片（更清晰，但竖图会被裁）。

**分级筛选（SFW / Sketchy / NSFW）**：高级筛选底部有三个独立开关，默认只开 SFW。只开某一个就只显示那一级（比如只开 Sketchy 就只看擦边内容），同时开多个就混合显示（例如 SFW+NSFW）；全关是不允许的，最后一次点击会被忽略。NSFW 这一项**只有登录后才出现**——App 会从账号设置页读 API key（只存本机、不写日志、不上传），NSFW 的列表和**详情页**都靠它才能加载；退出登录会自动关掉并刷新回 SFW。

**更多类似**：详情页标签栏右侧的「更多类似 ›」（⋯ 菜单里也有）会用这张图的标签 + 主色 + 相关度排序找相似壁纸。官网那个按钮实际是 `search?q=like:<id>`，但这个查询对 API 客户端会被 Cloudflare 拦成 403（带账号 API key 也一样），所以这里用公开 API 能做到的等效方式；标签组合太窄时会自动放宽容错，副标题会写清楚“找到 N 张 · 基于 X 个标签 + 主色”，底部列出完整匹配条件。

**分级角标**：卡片左上角会按分级标出来——**Sketchy 是黄色角标，NSFW 是红色角标**（和官网一致），SFW 不显示角标，扫一眼就知道这张图能不能在公共场合打开。详情页里的分级标签也用同样的配色。

**已下载管理**：设置 → 图库 → 已下载壁纸，会列出相册里 `Pictures/Wallhaven` 的文件（缩略图、文件名、大小），右上角垃圾桶删除（系统会再确认一次），点图片用系统看图打开。详情页下载时按钮里会走进度条，下载完变成「下载完成」，再点一下直接跳到这里。

**作者**：Zero-zl-0，主页 [github.com/Zero-zl-0](https://github.com/Zero-zl-0)。设置 → 关于作者里可以直接跳转；遇到问题建议把「运行日志」里的诊断信息一起发过去，定位会快很多。

**检查更新怎么工作的**：设置 → 关于 → 检查更新，会去读仓库的 Release（`releases/latest`）；有 Release 且带了 `.apk` 附件时，点「立即更新」就会下载并自动拉起系统安装器。下载前会先校验包名和签名，跟本机不一致会直接拒绝安装。仓库还没发 Release 时，只读仓库源码里的 `versionName` 做比对，并引导你去 GitHub 手动下载。

> 想让自动更新生效，每次发版都要在 GitHub 上创建 Release（tag 用 `v1.8.0` 这种形式），并把打包好的 APK 作为附件传上去。

**主题**：默认浅色，系统开深色模式后 App 立刻跟着变（不用重启），状态栏图标颜色也会自动适配。

**动效**：所有按钮都有按压缩放 + 弹簧回弹（不是生硬的 Material 水波纹）；底部 Tab 的选中底片会随选中项滑过去；收藏心心会“弹”一下；下载按钮点完会短暂变成「已开始下载」；卡片被按下时轻微缩小。系统开启「触摸振动」时还会有轻触反馈。

**下载的壁纸去哪了？** 手机相册的 `Pictures/Wallhaven/` 目录，文件名形如 `wallhaven-gw1rqe.jpg`。系统通知栏会显示下载进度。

**数据存在哪？** 收藏和历史存在 App 自己的本地存储里，不联网上传，卸载 App 会一起删掉。

## 四、几个必须知道的事

1. **NSFW（成人）内容看不到**。wallhaven 的 API 规定：NSFW 区必须带个人账号的 API key 才能读，本 App 没有做登录。所以只有 SFW 和可选的 Sketchy 内容。
2. **别商用**。这是非官方客户端，壁纸版权归原作者，下载后自己当桌面用就好。
3. **不需要账号**，打开就能用。
4. **手机网络需要能访问 wallhaven.cc**（见上文）。

## 五、出问题怎么办

| 现象 | 原因 / 处理 |
|---|---|
| 一直转圈或显示「连接超时」 | 手机连不上 wallhaven.cc，开 VPN/代理后点榜单右上角刷新 |
| 图片是灰色方块 | 缩略图下载失败，通常是网络抖了，往上滑再回来会重新加载 |
| 遇到报错想反馈 | 打开 设置 → 诊断 → 运行日志，点「错误」看红条目，再点右上角分享/复制发出来即可 |
| 登录后读不到云端收藏 | 先确认手机能打开 wallhaven.cc；再到 收藏 → 账号 点右上角刷新；仍失败看「运行日志」里的 Account 记录 |
| 同步提示失败 | 多半是网站改版导致接口变化，把运行日志里的 Account 记录发我，我按新结构适配 |
| 详情页信息面板挡住图 | 轻点图片即可收起（底部会留一个「查看信息」小把手，点它就回来） |
| 想看某个标签的所有图 | 详情页点那个 `#标签` 就会跳到搜索页按标签搜（也可以复制标签名自己搜） |
| 首页怎么全是竖屏（或横屏）图 | 这是「适配本机比例」的默认行为；点榜单顶部第一个开关「适配本机 / 全部比例」即可看全部 |
| 底部玻璃栏看着有点糊 | 这是刻意的背景模糊效果；系统低于 Android 12 时会退化成半透明色块 |
| 深色模式没跟着变 | 系统设置里切换「深色模式」后 App 会即时生效；若没变，检查是否给 App 单独设了强制浅色 |
| 提示「没有存储权限」 | 只有 Android 9 及更老系统会要这个权限，在系统设置里给「存储」权限 |
| 下载通知不见了/找不到文件 | 打开相册，在「Pictures/Wallhaven」相簿里；或文件管理器搜 wallhaven |

## 六、代码结构（想改东西时看这里）

```
wallhavenTools/
├── app/src/main/java/com/wallhaven/browser/
│   ├── MainActivity.kt              入口，全屏 + 跟随系统深浅色
│   ├── WhApplication.kt            启动日志 + 崩溃捕获
│   ├── data/
│   │   ├── Models.kt               接口返回的数据结构
│   │   ├── WallhavenApi.kt         请求 wallhaven 公开 API（搜索 + 详情）
│   │   └── LocalStore.kt           收藏/历史本地存储
│   ├── ui/
│   │   ├── WallhavenApp.kt         悬浮玻璃标签栏 + 页面路由
│   │   ├── components/Glass.kt     玻璃面板、胶囊标签、悬浮 Tab Bar、大标题
│   │   ├── components/Motion.kt    按压缩放 / 弹簧回弹 / 触感反馈 / iOS 按钮
│   │   ├── components/Components.kt 壁纸卡片、瀑布流、iOS 列表、空/错状态
│   │   ├── screens/                榜单/搜索/详情/收藏/历史/设置
│   │   ├── theme/Theme.kt          浅色 + 深色两套设计令牌、字体、圆角
│   │   └── vm/ViewModels.kt        分页加载、筛选状态、收藏状态
│   └── util/                       下载、格式化、分享/打开链接、屏幕比例识别、运行日志（AppLog）
├── app/src/main/res/               图标、应用名、浅色/深色启动背景
├── keystore/                       签名文件（别外传，换签名后 App 无法覆盖安装）
└── Wallhaven壁纸-v1.7.9.apk        打包好的安装包
```

**自己重新打包**（改完代码后）：

```powershell
$env:JAVA_HOME = 'C:\JDK\jdk-17.0.1'
C:\gradle-8.14.3\bin\gradle.bat -p D:\projects\wallhavenTools :app:assembleRelease
```

生成的 APK 在 `app\build\outputs\apk\release\app-release.apk`。

- 技术栈：Kotlin 2.1 + Jetpack Compose（Material 3）+ Haze（真实背景模糊）+ OkHttp + Coil
- 最低系统：Android 8.0（minSdk 26），编译用 SDK 35

## 七、自己编译（想改代码时看这里）

环境：JDK 17、Android SDK（compileSdk 35）。项目自带 Gradle Wrapper，不需要另外装 Gradle。

```bash
# 调试包（装到手机上看效果）
./gradlew :app:assembleDebug

# 正式包（需要签名文件）
./gradlew :app:assembleRelease
```

签名信息放在 `keystore/keystore.properties`，整个 `keystore/` 目录已写进 `.gitignore`，**不会上传到仓库**。格式：

```properties
storeFile=../keystore/wallhaven.jks
storePassword=你的密码
keyAlias=wallhaven
keyPassword=你的密码
```

产物在 `app/build/outputs/apk/release/app-release.apk`。

## 九、发版（维护者看这里）

仓库已经配好 GitHub Actions：**推送 `v*` 形式的 tag 会自动编译正式包并创建 Release**，不需要手工上传 APK。

每次发版三步：

```bash
# 1. 改版本号：app/build.gradle.kts 里 versionCode +1、versionName 改成新版本
# 2. 提交
git add -A && git commit -m "release: v1.8.2"

# 3. 打 tag 并推送（tag 必须和 versionName 一致，带 v）
git tag v1.8.2
git push origin main --tags
```

推完 tag 后到仓库 **Actions** 页面看一眼，`Build & Release APK` 跑完就会自动出现 Release，里面的 `Wallhaven-v1.8.2.apk` 就是给「检查更新」用的。

### 首次需要配一次 Secrets

Actions 编译正式包需要你的签名文件（keystore 不进仓库），所以在仓库 **Settings → Secrets and variables → Actions** 里加 4 个 secret：

| Secret 名 | 值 |
|---|---|
| `KEYSTORE_BASE64` | `keystore/wallhaven.jks` 的 base64（生成命令见下） |
| `KEYSTORE_PASSWORD` | `keystore/keystore.properties` 里的 `storePassword` |
| `KEY_ALIAS` | `keystore/keystore.properties` 里的 `keyAlias` |
| `KEY_PASSWORD` | `keystore/keystore.properties` 里的 `keyPassword` |

生成 base64 并在 PowerShell 里复制到剪贴板：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("D:\projects\wallhavenTools\keystore\wallhaven.jks")) | Set-Clipboard
```

> 注意：keystore 放进 Secrets 意味着「谁拿到这个仓库的管理权限，理论上就能签出可覆盖安装的包」。介意的话可以不用 Actions，改成在本机 `./gradlew :app:assembleRelease`，再去网页手动建 Release 上传 APK。
